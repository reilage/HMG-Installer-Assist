Stored answers

The first time a question is asked, Claude's answer is kept here. When an installer asks the same question again for the same unit, they get this answer straight away, free, and it doesn't use one of their questions for the day. Installers can tap "Didn't help" to get a fresh answer from Claude, which then replaces the stored one. Answers are cleared for a unit when its manuals or field notes change. Edit an answer to fix its wording: an edited answer stays even if an installer says it didn't help.
